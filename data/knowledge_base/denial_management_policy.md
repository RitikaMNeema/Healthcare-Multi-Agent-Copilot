# Denial Management Policy

Denial codes are grouped into five root-cause categories: administrative (missing or invalid information), eligibility, medical necessity, authorization, and timely filing. Each denied claim must be triaged into exactly one category before a remediation action is chosen, since the correct fix differs by category.

Code CO-16 means the claim or service lacks information needed for adjudication - this is an administrative denial and is almost always resolved by resubmitting with the missing field, most commonly a diagnosis code or a referring provider NPI.

Code CO-50 means the service is non-covered because it was not deemed a medical necessity. This is a clinical denial and requires a letter of medical necessity with supporting documentation from the treating provider before it can be appealed successfully.

Code CO-97 means the benefit for the billed service is already included in payment for another procedure that was already adjudicated - typically a bundling issue. This is usually resolved by verifying correct use of modifier codes rather than by appeal.

Code PR-1 means the amount denied is the patient's deductible responsibility. This is not a payer error and is not eligible for a provider appeal; it should be billed directly to the patient.

Code CO-197 means precertification or authorization was absent at the time of service. This is an authorization denial. If authorization can be obtained retroactively from the payer, the claim should be appealed with the retroactive authorization number attached.

Code CO-29 means the timely filing limit expired before the claim was submitted. This is the hardest denial category to overturn on appeal, since it requires proof that the claim was submitted on time despite the payer's records showing otherwise (for example, a clearinghouse timestamp).

High-denial-rate procedure and payer combinations should be reviewed monthly. Any procedure-payer pair with a denial rate above 25% over a rolling 90-day window should trigger a root-cause review and, where appropriate, a remediation plan.
